# seminar-cpe-narongkon

Repository สำหรับเก็บงานวิชาการสัมมนาทางวิศวกรรมคอมพิวเตอร์

## เกี่ยวกับ Repository นี้

Repository นี้ใช้เก็บงานและเอกสารประกอบรายวิชาการสัมมนาทางวิศวกรรมคอมพิวเตอร์ เพื่อฝึกใช้งาน Git และ GitHub ตั้งแต่การสร้าง Repository การเขียนไฟล์ Markdown ไปจนถึงการ commit และ push ขึ้น GitHub

## ไฟล์ในนี้

- `README.md` — เอกสารอธิบาย Repository
- `narongkon.md` — ไฟล์แนะนำตัว
